## Запуск

Распакуйте архив и откройте `index.html` в браузере. Файлы `style.css` и `app.js` должны лежать рядом с ним. Также страницу можно открыть через расширение Live Server в VS Code.

Для запросов к JSONPlaceholder нужен интернет. Установка библиотек и серверная часть не требуются.

## Работа с приложением

Нажмите «Загрузить публикации», чтобы получить пять записей из общей ленты. Для создания своей публикации заполните «Заголовок» и «Текст» и отправьте форму. Под формой появятся заголовок, текст и ID из ответа сервера.

Во время запроса показывается сообщение о загрузке или отправке, соответствующая кнопка блокируется. При ошибке доступна повторная попытка; введённый текст сохраняется в форме. Если повторная загрузка списка не удалась, ранее полученные записи остаются видны.

JSONPlaceholder имитирует создание публикаций и не сохраняет их постоянно. Созданная запись показывается отдельно от загруженного списка.

## Результаты проверки

- GET на `/posts?_limit=5` вернул HTTP 200. На странице появились пять записей с заголовками и текстами.
- Пустая форма и поля из пробелов вызвали ошибки на странице. POST-запросы не отправлялись.
- Публикация «Заметки с практикума» успешно отправлена. Пробелы по краям удалены; запрос содержал `title`, `body`, `userId: 1` и заголовок `Content-Type: application/json`. Сервер вернул HTTP 201 и ID 101, результат появился под формой.
- Во время GET и POST отображались сообщения о выполнении запроса, кнопки были недоступны.
- Обращение к `/postz` вернуло HTTP 404. Приложение показало ошибку и разблокировало кнопку; повторный запрос к правильному адресу прошёл успешно.
- При имитации обрыва сети GET и POST завершились понятными сообщениями об ошибках. После неудачного POST текст остался в форме, повторная отправка сработала.
- Интерфейс проверен на широком и узком экране. Страница обновлялась без перезагрузки, ошибок JavaScript не обнаружено.

Для ручной проверки GET 404 временно замените значение `GET_URL` в `app.js` на `https://jsonplaceholder.typicode.com/postz`, обновите страницу и нажмите кнопку загрузки. После проверки верните `https://jsonplaceholder.typicode.com/posts?_limit=5`. В сдаваемом файле указан правильный адрес.
